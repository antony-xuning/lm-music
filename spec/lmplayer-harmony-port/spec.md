# Feature Specification: LMPlayer 柠檬音乐 · HarmonyOS 服务器接入版

**Created**: 2026-11-21（v2，范围变更）
**Status**: Draft
**Input**: 用户需求："该app作为手机端，服务器端是部署在飞牛上的，服务器端的介绍如地址：https://github.com/jia070310/lemon-muisc，结合地址，打通app与服务器端的连接。" 澄清结论：登录 + 曲库同步 + 在线播放（含封面/歌词）+ 收藏与歌单双向同步；删除内置演示数据，未连接服务器时仅空态+重试；保留本地音频导入播放。

## Overview

在既有 HarmonyOS 版 LMPlayer（柠檬音乐）基础上，把数据源从内置演示目录切换为**用户自建的柠檬音乐服务端**（部署于飞牛 NAS），实现真实登录鉴权、服务器曲库同步、服务器曲目在线播放、封面与歌词获取、收藏/自建歌单双向同步，以及发现页的服务器榜单、新歌首发、新碟首发与推荐歌单。

本轮同时进行首页与底栏重构：原「发现」页签更名为「首页」，首页提供「本地曲库 / 柠檬音乐服务器」模式切换——本地模式展示用户授权文件夹的扫描结果与最近添加，服务器模式保留榜单/新歌/新碟/推荐；没有服务器时默认进入本地模式。底部导航栏改为华为音乐风格的整宽玻璃 Dock（顶部高光扫过、选中图标放大、标签渐现、专辑主色染色）。

应用作为手机端与服务器通过 HTTP(S) 直连：服务器地址与账号在应用内配置，登录 Token 持久化（含过期时间），密码仅在本次会话内存中用于重登、不落盘；服务端不可达或未配置时，所有服务器内容页展示空态、错误原因与重试入口，不再展示任何内置演示曲库。用户已导入到设备的本地音频仍可独立播放。

**目标平台与硬性约束**

- 平台：HarmonyOS 26.0.0（API 26），compileSdkVersion / targetSdkVersion / compatibleSdkVersion 均为 26。
- 网络：申请 `ohos.permission.INTERNET`；允许局域网 HTTP 明文直连（服务端若为 HTTPS 则需有效证书）。
- 数据源：以服务器为唯一在线数据源，不使用任何内置演示歌曲/榜单/播客数据。
- 视觉：保留沉浸光感（悬浮底栏、标题栏、Slider/Toggle/Select、弹窗与半模态）与深/浅色主题。
- 语言：简体中文。
- 凭据：密码/Token 仅保存在本机应用沙箱；不得写入日志、不得提交到仓库、不得出现在错误提示中。

## User Scenarios & Testing *(mandatory)*

### 用户故事 1 - 配置服务器并完成登录 (Priority: P1)

用户在「设置 · 账号音源」新增服务器：填写名称、基础地址（如 `http://192.168.1.10:7983`）、用户名、密码，点击「连接测试」。应用先探活服务端，再调用登录接口换取 Token；成功后显示当前服务器名称、在线状态、登录用户与延迟，并将服务器配置与 Token（含过期时间）持久化，密码不落盘。

**Why this priority**: 没有可信的登录会话，后续曲库、播放、收藏全部无法工作。

**Independent Test**: 仅实现本故事即可验收：输入正确地址与账号 → 连接测试显示成功；输入错误密码 → 显示明确失败原因；杀掉进程重启 → 仍显示已连接且无需重新输入密码。

**Acceptance Scenarios**:

1. **Given** 应用首次启动且未配置服务器，**When** 进入设置页，**Then** 显示「未连接服务器」与「添加服务器」入口。
2. **Given** 已填写正确的地址、用户名、密码，**When** 点击「连接测试」，**Then** 依次完成健康探活与登录，并显示「连接成功」及服务器名称、用户、延迟。
3. **Given** 已填写错误的密码，**When** 点击「连接测试」，**Then** 显示可读的失败原因（如"账号或密码错误"），不崩溃，且不清空已填写内容。
4. **Given** 地址不可达（局域网断开/端口错误），**When** 点击「连接测试」，**Then** 在超时时间内返回「无法连接服务器」并给出检查建议。
5. **Given** 连接成功，**When** 杀掉应用进程后重新打开，**Then** 自动使用已保存的 Token 校验会话，直接显示已连接状态。
6. **Given** 服务端返回 401（Token 过期），**When** 应用发起任意请求，**Then** 若当前会话仍持有密码则自动重登一次；冷启动后 Token 失效则提示"登录已过期，请重新输入密码"，不得把过期 Token 当密码再次登录。
7. **Given** 存在多条服务器配置，**When** 切换激活服务器，**Then** 立即使用新地址与新会话，旧服务器缓存不串用。

### 用户故事 2 - 同步并浏览服务器曲库 (Priority: P1)

登录成功后，应用自动同步服务器曲库：按页拉取曲目（每页 200），并拉取专辑、歌手、歌单与用户数据（收藏、最近播放）。同步完成后，「资料库」展示真实数量；「发现」页展示服务器最近添加、专辑、歌手与歌单；列表支持搜索、排序与二级下钻。

**Why this priority**: 曲库是应用的主要内容，决定登录后是否有可用数据。

**Independent Test**: 使用一个有若干曲目的服务器，登录后触发同步，资料库数量与服务器一致；断网后重启仍可浏览上次同步的缓存；下拉刷新能拉到新增曲目。

**Acceptance Scenarios**:

1. **Given** 已完成登录，**When** 进入资料库，**Then** 自动触发（或复用 1 分钟内）同步，显示曲目/专辑/歌手/歌单真实数量。
2. **Given** 服务器有 N 首曲目且分多页，**When** 同步完成，**Then** 本地曲目数量等于 N（不重复、不遗漏）；单页失败时整体标记失败，不写入残缺列表。
3. **Given** 曲目列表，**When** 按标题/歌手搜索或按加入时间/标题/时长排序，**Then** 结果实时更新。
4. **Given** 点击某专辑/歌手/歌单，**Then** 进入二级页并展示对应曲目，返回后列表位置与筛选状态保留。
5. **Given** 同步进行中，**When** 查看顶部状态区，**Then** 显示"正在同步/已同步/失败"及最后同步时间。
6. **Given** 服务器离线且已有缓存，**When** 打开资料库，**Then** 展示缓存内容并标注"离线数据，最后同步于 …"。
7. **Given** 服务器曲目数为 0，**Then** 显示空态与「刷新」入口，不显示假数据。

---

### 用户故事 3 - 播放服务器曲目、封面与歌词 (Priority: P1)

用户在任意列表点击服务器曲目即可在线播放：音频流请求携带登录 Token，封面通过带鉴权的缓存服务加载，歌词优先读取服务端内嵌/同名 LRC，失败再请求在线歌词接口。全屏播放器的封面、标题、歌手、专辑、进度与歌词均来自服务器数据。

**Why this priority**: 在线播放是接入服务器后的核心价值；没有它，曲库只能浏览不能使用。

**Independent Test**: 在服务器上选一首曲目播放，能听到声音且进度推进；封面正常显示；带时间戳歌词随进度高亮；暂停/拖动/切歌正常。

**Acceptance Scenarios**:

1. **Given** 已登录且曲库已同步，**When** 点击服务器曲目，**Then** 2 秒内开始播放，迷你播放器显示封面、标题、歌手。
2. **Given** 服务器曲目格式为 FLAC/MP3，**When** 播放，**Then** 进度条按真实时长推进，可拖动跳转并在跳转后继续播放。
3. **Given** 曲目有封面标记，**When** 列表与播放器渲染封面，**Then** 封面经鉴权下载并缓存，重复进入不重复下载，不出现破损图。
4. **Given** 曲目存在内嵌歌词或同名 .lrc，**When** 打开歌词页，**Then** 展示逐行歌词并随进度高亮；无逐行时间戳时按纯文本展示。
5. **Given** 内嵌歌词不存在，**When** 服务端在线歌词接口可用，**Then** 请求并展示歌词；接口失败时展示"暂无歌词"空态，不影响播放。
6. **Given** 播放中网络中断，**When** 音频缓冲耗尽，**Then** 显示播放错误提示并允许重试；应用不崩溃。
7. **Given** 播放服务器曲目，**When** 切到后台再返回，**Then** 播放状态与进度保持（前台生命周期内）。

---

### 用户故事 4 - 收藏与自建歌单双向同步 (Priority: P2)

用户点击红心或管理自建歌单时，应用把变更写回服务器：先读取完整用户数据，再在本地修改，最后整表提交。读取失败时中止写入并提示，绝不覆盖服务器数据；写入成功后多端可见。

**Why this priority**: 收藏与歌单是长期资产，写回能力决定多端体验是否闭环。

**Independent Test**: 在服务器已有一批收藏的前提下，收藏/取消收藏一首歌，重新登录或刷新后状态一致；创建/重命名/删除歌单与增删曲目后，服务器端数据同步变化。

**Acceptance Scenarios**:

1. **Given** 曲目未收藏，**When** 点击红心，**Then** 图标立即点亮，服务器用户数据中的收藏新增该曲目；刷新后仍为已收藏。
2. **Given** 曲目已收藏，**When** 再次点击红心，**Then** 本地取消并写回服务器，刷新后不再出现。
3. **Given** 读取服务器用户数据失败（网络/5xx），**When** 用户点击红心，**Then** 中止写入并提示"读取服务器收藏失败，已取消本次修改"，服务器数据保持不变。
4. **Given** 新建歌单，**When** 输入名称并确认，**Then** 服务器歌单列表新增该歌单，名称为用户输入。
5. **Given** 歌单详情，**When** 加入/移除曲目，**Then** 服务器歌单的曲目键与快照同步更新。
6. **Given** 重命名或删除自建歌单，**When** 确认操作，**Then** 服务器端同步变化；删除需二次确认。
7. **Given** 并发触发两次收藏写操作，**When** 两次请求先后完成，**Then** 不出现相互覆盖导致收藏丢失（写入串行化）。

---

### 用户故事 5 - 未连接/离线时的空态与恢复 (Priority: P2)

在未配置服务器、登录失效或网络不可达时，服务器相关页面不显示任何演示内容，而是展示明确的空态、失败原因与操作入口（去设置/重新登录/重试）；本地已导入的音乐仍可正常浏览与播放。

**Why this priority**: 明确失败状态可避免用户误以为数据丢失，也避免假数据误导。

**Independent Test**: 清空配置并断网，逐页检查发现/资料库/搜索/播放器，均显示空态且有可用入口；恢复网络并登录后内容自动出现。

**Acceptance Scenarios**:

1. **Given** 未配置服务器，**When** 打开发现页或资料库，**Then** 显示"尚未连接柠檬音乐服务器"与「去设置」按钮。
2. **Given** 已配置但网络不可达，**When** 打开资料库，**Then** 显示失败原因与「重试」按钮；点击重试触发一次同步。
3. **Given** 已有缓存但网络不可达，**When** 浏览列表，**Then** 展示缓存并明确标注离线状态。
4. **Given** 播放服务器曲目失败，**When** 错误发生，**Then** 显示错误提示且队列可继续下一首。
5. **Given** 本地已导入音频，**When** 服务器不可用，**Then** 本地曲目仍可播放，列表不混入演示歌曲。
6. **Given** 从离线恢复为在线，**When** 点击刷新，**Then** 数据更新且离线标记消失。

---

### 用户故事 6 - 本地音频与服务器曲目并存 (Priority: P3)

用户通过系统文件选择器导入本机音频后，该曲目与服务器曲目出现在同一「全部歌曲」列表中，并以来源徽章区分；本地曲目可播放、可删除，服务器曲目不可删除本地文件。

**Why this priority**: 保留既有本地播放能力，同时不与服务器数据混淆。

**Independent Test**: 导入一个本地文件，列表出现"本地"徽章；播放正常；服务器曲目显示"服务器"徽章且无删除本地文件操作。

**Acceptance Scenarios**:

1. **Given** 已连接服务器，**When** 导入本地音频，**Then** 该曲目以「本地」来源出现在全部歌曲与最近添加中。
2. **Given** 列表同时含两类曲目，**When** 查看列表项，**Then** 来源徽章正确区分，统计数量分别计入。
3. **Given** 本地曲目，**When** 选择删除，**Then** 二次确认后移除记录与沙箱文件。
4. **Given** 服务器曲目，**When** 打开更多操作，**Then** 不提供"删除本地文件"，仅提供加入歌单/收藏等。

---

### 用户故事 7 - 服务器状态与全局搜索 (Priority: P3)

「设置 · 账号音源」展示服务器在线状态、延迟、最后同步时间、曲库数量，并提供「立即同步」「清空缓存」「退出登录」；全局搜索在当前已同步曲库（服务器+本地）中按歌曲/专辑/歌手过滤。

**Why this priority**: 状态可见与检索能力让接入后的应用可运维、可日常使用。

**Independent Test**: 设置页各项状态真实反映服务器；搜索关键词返回服务器曲目并可直接播放。

**Acceptance Scenarios**:

1. **Given** 已登录，**When** 打开账号音源，**Then** 显示在线状态、延迟、最后同步时间与曲目数量。
2. **Given** 账号音源，**When** 点击「立即同步」，**Then** 触发同步并更新状态与数量。
3. **Given** 账号音源，**When** 点击「退出登录」，**Then** 清除本机 Token 并回到未连接空态；再次操作需重新输入密码。
4. **Given** 搜索页，**When** 输入关键词并按歌曲范围检索，**Then** 返回已同步曲库中的匹配项，点击可播放。
5. **Given** 搜索无结果，**Then** 展示空态与「重试」，不清空关键词。

---

### 用户故事 8 - 首页 · 服务器模式真实榜单与推荐 (Priority: P2)

登录后，「发现」页展示服务器返回的真实内容：可切换音源（酷我/网易/QQ/酷狗/咪咕），查看权威榜单（36 个）、榜单曲目、新歌首发、新碟首发与热门推荐歌单；点击歌曲可直接试听，点开歌单/专辑可查看曲目列表。

**Why this priority**: 发现页是内容发现入口；接入真实数据后才具备"每天有新内容"的价值。

**Independent Test**: 仅接入发现接口即可验收：榜单数量与服务器一致；点开榜单看到曲目并播放；新碟/推荐歌单可下钻；切换音源后内容变化。

**Acceptance Scenarios**:

1. **Given** 已登录，**When** 进入发现页，**Then** 展示服务器返回的榜单列表（默认酷我，数量与 `/api/discover/toplists` 一致）、新歌、新碟与推荐歌单。
2. **Given** 发现页，**When** 切换音源为网易云/QQ/酷狗/咪咕，**Then** 重新拉取该音源的榜单与推荐，并保留当前页面状态。
3. **Given** 点击某榜单，**Then** 进入榜单曲目列表并展示排名、歌名、歌手、时长；点击曲目开始播放。
4. **Given** 点击某新碟专辑，**Then** 通过服务端专辑详情接口获取曲目列表并展示。
5. **Given** 点击某推荐歌单，**Then** 通过服务端歌单解析接口获取曲目列表并展示，可播放全部。
6. **Given** 在线榜单/推荐接口失败（服务端第三方源不可用），**Then** 展示该区块的错误态与「重试」，其他区块仍可用。
7. **Given** 未登录或离线，**Then** 发现页显示空态与「去设置」，不展示任何演示榜单。

---

### 用户故事 9 - 全网搜索与在线试听 (Priority: P2)

用户打开搜索，切换「歌曲 / 专辑 / 歌单」范围并输入关键词，获得服务器聚合的全网结果；点击歌曲可在线试听，并可收藏或加入自建歌单；点击专辑/歌单可查看曲目。

**Why this priority**: 搜索是曲库之外的内容获取入口，也是服务器聚合能力的核心体现。

**Independent Test**: 搜索"周杰伦"返回歌曲/专辑；搜索"古风"返回歌单；点歌曲 2 秒内出声；收藏后服务器收藏新增。

**Acceptance Scenarios**:

1. **Given** 已登录，**When** 输入关键词并选择「歌曲」，**Then** 调用 `/api/search` 返回结果并展示歌名、歌手、专辑、音源与音质标签。
2. **Given** 搜索界面，**When** 切换到「专辑」或「歌单」，**Then** 分别调用 `/api/search/album`、`/api/search/playlist` 并展示对应结果。
3. **Given** 搜索结果歌曲，**When** 点击，**Then** 通过签名接口解析播放地址并开始试听。
4. **Given** 搜索结果，**When** 点击收藏或加入歌单，**Then** 按 US4 的写回规则同步服务器。
5. **Given** 结果专辑/歌单，**When** 点击进入，**Then** 调用专辑/歌单详情接口展示曲目列表。
6. **Given** 音源不可用导致搜索失败，**Then** 展示失败原因与重试，不清空已输入关键词。

---

### 用户故事 10 - 服务器下载任务管理 (Priority: P2)

用户在服务器曲库、搜索结果或歌单中对歌曲发起下载（保存到服务器），在「下载」页查看服务端任务列表、进度与状态，支持暂停、继续、重试、删除单条与清空已完成。

**Why this priority**: 服务器下载是把在线内容沉淀为曲库的主要方式，与曲库同步形成闭环。

**Independent Test**: 提交 1 首下载，任务出现在列表并推进；暂停后进度停止；继续后恢复；完成后曲库出现该曲目；删除/清空生效。

**Acceptance Scenarios**:

### 用户故事 16 - 顶部系统实况窗（AVSession 灵动岛） (Priority: P2)

应用接入 AVSession（audio 类型）并申请后台播放长时任务：系统播控中心、状态栏实况胶囊与锁屏自动展示当前歌曲封面、标题、歌手、进度与歌词；用户可在系统界面播放/暂停、上一首/下一首、拖动进度、切循环模式与收藏。应用切后台/锁屏继续播放。

**Why this priority**: 音乐类"灵动岛"在 HarmonyOS 上的标准形态是 AVSession 驱动的系统实况窗；同时解决后台播放被系统暂停的问题。

**Independent Test**: 播放任意歌曲后下拉通知中心/锁屏，能看到歌曲信息与控制；在系统播控点击暂停/下一首，应用内状态同步；切后台 30 秒后音乐仍播放。

**Acceptance Scenarios**:

1. **Given** 应用开始播放，**Then** 创建并激活 audio 类型 AVSession，设置元数据（assetId/title/artist/album/duration/封面）与播放状态。
2. **Given** 播放中，**Then** 系统通知中心/状态栏实况胶囊/锁屏展示当前歌曲封面、标题、歌手与进度（设备支持时）。
3. **Given** 播放中，**Then** 系统界面提供播放/暂停、上一首、下一首、进度、循环模式与收藏控制。
4. **Given** 在系统播控点击暂停/播放/下一首/收藏/切循环，**Then** 应用内播放器与界面状态在 1 秒内同步。
5. **Given** 系统拖动进度，**Then** 应用 seek 到对应位置并继续播放。
6. **Given** 切歌，**Then** 元数据、封面与歌词（LRC）更新，进度从 0 开始。
7. **Given** 应用切后台或锁屏，**Then** 播放继续（已申请 audioPlayback 长时任务），30 秒内不中断。
8. **Given** 队列清空/停止播放，**Then** 结束实况窗并取消长时任务。
9. **Given** 系统不支持 AVSession 实况窗/权限被拒，**Then** 应用内播放不受影响，仅缺少系统展示。

### 用户故事 19 - 播放器收缩/展开动画 (Priority: P2)

点击迷你播放器时，全屏播放器从迷你播放器所在位置放大展开；关闭时反向缩小并落回迷你播放器位置，与底栏融为一体。若从折叠态打开，则落回紧凑胶囊位置。动画 ≤320ms、可中断，过程中不出现重复播放器或页面闪烁。

**Why this priority**: 参考华为音乐的"播放器与底栏连续过渡"，让全屏与迷你态之间的空间关系清晰、手感高级。

**Independent Test**: 反复打开/关闭播放器 10 次：展开起点为迷你播放器矩形、关闭终点为其矩形；折叠态打开时落回紧凑胶囊；无白屏/跳变。

**Acceptance Scenarios**:

1. **Given** 迷你播放器显示，**When** 点击播放器区域，**Then** 全屏播放器从迷你播放器的位置与尺寸放大到全屏（≤320ms）。
2. **Given** 全屏播放器，**When** 点击关闭/下拉，**Then** 播放器缩小并移动到迷你播放器矩形后消失，同时迷你播放器出现。
3. **Given** 折叠态（紧凑胶囊），**When** 打开并关闭播放器，**Then** 播放器落回紧凑胶囊矩形，底栏保持折叠态。
4. **Given** 动画进行中，**When** 再次点击关闭/打开，**Then** 动画从当前位置平滑反向或完成，不叠加两层播放器。
5. **Given** 有/无封面，**Then** 过渡中封面/标题/控制区不闪白、不出现错误占位。
6. **Given** 搜索/队列/歌词调节浮层打开，**Then** 关闭播放器时先关闭浮层再收缩。
7. **Given** 旋转/分屏，**Then** 目标矩形按当前窗口重新计算，落点仍准确。

### 边界场景

- 服务器返回 HTML 登录页/反向代理错误页而非 JSON：判定为"不是柠檬音乐服务"，不得当作登录成功。
- 服务器分页接口忽略 page 参数：以"本页无新增路径"结束循环，避免死循环。
- 曲库 0 首、歌单 0 个、收藏 0 条：均为合法状态，展示空态而非错误。
- 同一曲目在服务器被移动/删除后同步：本地标记为失效，播放时提示并跳过。
- 用户修改服务器地址但保留旧 Token：不得把旧 Token 发给新主机。
- 服务器时间与本地时间偏差：最后同步时间以本地接收时间记录。
- 网络切换（Wi-Fi ↔ 蜂窝）：正在播放的流中断时给出提示并可重试。
- 应用被杀死后重启：会话、曲库缓存、收藏/歌单最后状态可恢复。

**A. 服务器配置与鉴权**

- **FR-001**：应用 MUST 提供服务器配置界面，支持名称、基础地址、用户名、密码的填写、编辑与删除。
- **FR-002**：应用 MUST 规范化服务器地址（去尾部斜杠、校验协议为 http/https、拒绝空地址与非法 URL）。
- **FR-003**：应用 MUST 支持多服务器配置并标记唯一激活服务器，切换后所有请求使用新配置且不串用旧 Token。
- **FR-004**：连接测试 MUST 先做健康探活（`/api/health`，失败回退 `/api/auth/me`），再执行登录，避免把反向代理登录页误判为成功。
- **FR-005**：登录 MUST 使用 `POST /api/auth/login`（username/password/remember），成功后保存返回的 Token 与过期时间，并用于后续 `Authorization: Bearer`。
- **FR-006**：应用 MUST 支持用已保存 Token 调用 `/api/auth/me` 校验会话；返回 401 时，仅当本次会话仍持有密码才自动重登一次，否则清除会话并提示重新登录。
- **FR-007**：Token MUST 仅存放于本机沙箱并记录过期时间；密码 MUST NOT 持久化、不得写入日志或出现在界面提示；「退出登录」MUST 清除 Token。
- **FR-008**：应用 MUST 申请 `ohos.permission.INTERNET`，并支持局域网 HTTP 明文地址。
- **FR-009**：所有服务器请求 MUST 设置连接/读取超时，并在超时后返回可读错误，不无限等待。

**B. 曲库同步**

- **FR-010**：应用 MUST 在登录成功后自动触发一次曲库同步；同一分钟内重复进入资料库不重复触发。
- **FR-011**：曲目同步 MUST 分页请求 `/api/library/tracks?page=N&limit=200`，兼容 `data[]`、`data.list[]`、`list[]` 三种响应信封。
- **FR-012**：同步 MUST 校验分页终止条件（本页数量不足、无新增路径、达到 total、页数上限），避免死循环与重复数据。
- **FR-013**：同步 MUST 拉取 `/api/library/albums`、`/api/library/artists`、`/api/library/user-data`（收藏/歌单/最近播放），并对 `/api/library/playlists` 做兼容回退。
- **FR-014**：任一页失败 MUST 使本次同步整体失败，不得用残缺列表覆盖已有缓存。
- **FR-015**：同步结果 MUST 写入本地缓存（曲目、专辑、歌手、歌单、收藏、最近播放、最后同步时间、服务器标识）。
- **FR-016**：应用 MUST 展示同步状态（未同步/同步中/成功/失败）与最后同步时间。
- **FR-017**：资料库 MUST 提供「全部歌曲 / 专辑 / 歌手 / 歌单 / 收藏 / 最近播放」入口，数量来自真实同步结果。
- **FR-018**：列表 MUST 支持按标题/歌手关键词过滤，并支持按加入时间、标题、时长排序。
- **FR-019**：专辑/歌手/歌单 MUST 支持二级页下钻并只展示其所属曲目。
- **FR-020**：切换服务器或退出登录 MUST 使对应缓存失效，不得把 A 服务器的数据展示到 B 服务器下。

**C. 在线播放**

- **FR-021**：播放前 MUST 调用 `POST /api/play/url` 换取带票据的播放地址：服务器文件传 `source=local` + `filePath`/`trackId`，在线来源曲目传 `source=<平台>` + `songId/songmid/hash/copyrightId`；相对地址 MUST 补全为服务器绝对地址。
- **FR-022**：签名地址 MUST 在有效期内缓存（约 10 分钟）并优先使用；签名接口失败时 MUST 回退 `/api/play/local` 并使用带 `Authorization` 头的媒体源，不得播放未鉴权地址。
- **FR-022a**：歌单与最近播放中的「在线来源」条目（如 `wy:`、`kw:`）MUST 可被解析并播放；不得因缺少本地路径而丢弃或显示为不可用。
- **FR-022b**：音质偏好 MUST 映射为 `128k/320k/flac/flac24bit` 并透传给签名接口；服务端返回的实际格式 MUST 用于界面徽章。
- **FR-023**：AVPlayer MUST 支持 HTTP Range 串流、播/暂停、seek、上一首/下一首、播放完成与错误回调。
- **FR-024**：曲目 MUST 保存服务器文件路径与可选 trackId，用于构造流地址、封面地址与歌词请求。
- **FR-025**：封面 MUST 通过带鉴权的下载缓存加载：`/api/tag/cover?path=<编码路径>&v=<mtime>`，缓存命中不重复请求；下载失败回退程序化占位封面。
- **FR-026**：歌词 MUST 优先请求 `POST /api/tag/read`（filePath/path）读取内嵌或同名 .lrc；为空或失败时请求 `POST /api/play/lyric`。
- **FR-027**：歌词文本 MUST 兼容 `lxlyric`、`lyric`、`ylyric` 字段，并处理常见乱码/转义；无歌词时展示空态。
- **FR-028**：服务器曲目 MUST 支持四种播放模式与播放队列，与本地曲目共用同一播放器。
- **FR-029**：播放失败 MUST 展示错误原因，并允许继续播放队列中的下一首。

**D. 收藏与歌单写回**

- **FR-030**：收藏状态 MUST 以服务器 `favorites` 为准，本地仅作缓存。
- **FR-031**：收藏/取消收藏 MUST 先 GET `/api/library/user-data`，修改 `favorites` 后 PUT 回同一接口；GET 失败 MUST 中止写入。
- **FR-032**：收藏条目 MUST 包含可被服务端识别的 key/localPath/filePath/name/source 等字段，取消收藏 MUST 能匹配旧格式条目（字符串键或对象）。
- **FR-033**：自建歌单的新建/重命名/删除/增删曲目 MUST 通过读取现有歌单数组 → 修改 → PUT `/api/library/playlists` 完成；读取失败 MUST 中止。
- **FR-034**：歌单曲目 MUST 使用 `trackKeys` 与 `trackSnapshots` 结构，并保留服务端既有字段类型（字符串或对象）。
- **FR-035**：写操作 MUST 串行执行，避免并发读改写相互覆盖。
- **FR-036**：写回成功后 MUST 更新本地缓存并使用户界面立即反映；失败时 MUST 回滚界面状态并提示原因。

**E. 离线与空态**

- **FR-037**：未配置服务器时，发现/资料库/搜索 MUST 显示"未连接服务器"空态与「去设置」入口。
- **FR-038**：已配置但不可达时 MUST 显示失败原因与「重试」；重试触发一次同步。
- **FR-039**：有缓存但离线时 MUST 允许浏览缓存，并标注"离线数据，最后同步于 …"。
- **FR-040**：应用 MUST NOT 在任何页面展示内置演示歌曲、演示榜单或演示播客内容。
- **FR-041**：播客与下载页在未登录/离线时 MUST 展示空态与重试，不得展示假任务/假单集。
- **FR-042**：本地导入音频 MUST 在离线时仍可浏览与播放。

**F. 本地音频与搜索**

- **FR-043**：本地音频导入 MUST 继续使用系统文件选择器，复制到应用沙箱并持久化。
- **FR-044**：曲目列表 MUST 以徽章区分「服务器 / 本地」来源，并分别统计数量。
- **FR-045**：删除本地曲目 MUST 二次确认并移除沙箱文件；服务器曲目 MUST NOT 提供删除本地文件操作。
- **FR-046**：全局搜索 MUST 覆盖已同步的服务器曲库、本地曲库与在线聚合结果，并按歌曲/专辑/歌单范围展示。
- **FR-047**：在线搜索 MUST 调用服务端 `/api/search` 系列接口，不得使用内置假数据；失败时保留关键词并允许重试。

**G. 服务器状态与设置**

- **FR-048**：账号音源页 MUST 展示在线状态、延迟、最后同步时间、曲目数量与当前用户。
- **FR-049**：账号音源页 MUST 提供「立即同步」「清空缓存」「退出登录」「删除服务器」操作，危险操作需二次确认。
- **FR-050**：设置项与服务器配置 MUST 持久化，冷启动后恢复；修改后 MUST 立即生效。
- **FR-051**：关于页 MUST 展示应用名、版本、开源许可、免责声明，以及"服务端数据由用户自建服务器提供"的说明。

**H. 视觉与适配（保留既有能力）**

- **FR-052**：应用 MUST 保持沉浸光感（悬浮底栏、标题栏、Slider/Toggle/Select、弹窗/半模态）与深/浅色主题。
- **FR-053**：所有服务器内容页 MUST 具备加载/空/错误/离线四种状态，且状态切换不影响导航。
- **FR-054**：应用 MUST 在手机竖屏、横屏、平板下保持布局可用；长标题/长歌手名不得溢出。
- **FR-055**：所有网络操作 MUST 提供可见反馈（同步进度、按钮 loading、失败 Toast），且不阻塞 UI 线程。

**I. 发现页在线数据**

- **FR-061**：首页 · 服务器模式 MUST 从 `GET /api/discover/toplists?source=<平台>` 拉取榜单列表，并展示名称、封面、更新时间与曲目数。
- **FR-062**：点击榜单 MUST 调用 `GET /api/discover/toplist?source=<平台>&id=<榜单ID>&limit=N` 拉取曲目并进入榜单曲目页。
- **FR-063**：首页 · 服务器模式 MUST 展示 `GET /api/discover/new-songs?source=<平台>&limit=N` 返回的新歌首发，并支持点击播放。
- **FR-064**：首页 · 服务器模式 MUST 展示 `GET /api/discover/new-albums?source=<平台>&limit=N` 返回的新碟首发；点击后 MUST 调用 `GET /api/album?source=<平台>&id=<专辑ID>` 获取曲目。
- **FR-065**：首页 · 服务器模式 MUST 展示 `GET /api/playlist/recommend?source=<平台>&sort=hot&page=1&limit=N` 返回的推荐歌单；点击后 MUST 调用 `GET /api/playlist?source=<平台>&url=<歌单ID>` 获取曲目。
- **FR-066**：应用 MUST 支持音源切换（kw/wy/tx/kg/mg），切换后重新拉取发现数据，并持久化用户选择。
- **FR-067**：在线歌曲 MUST 解析 `id/name/singer/album/interval/source/songId/songmid/hash/copyrightId/picUrl/img/qualitys` 等字段；`interval` MUST 兼容 `"mm:ss"` 与秒数两种格式；`qualitys` MUST 兼容字符串（空格分隔）与数组两种形式。
- **FR-068**：在线歌曲封面 MUST 支持外链图片下载缓存；封面缺失时使用程序化占位，不出现破图。
- **FR-069**：首页 · 服务器模式 MUST 按区块独立展示加载/成功/失败状态；单区块失败不得导致整页不可用。
- **FR-070**：首页 · 服务器模式数据 MUST 做短时内存缓存（约 5 分钟，按音源区分），避免频繁切换重复请求。

**J. 全网搜索**

- **FR-071**：搜索 MUST 支持歌曲/专辑/歌单三个范围，分别调用 `/api/search`、`/api/search/album`、`/api/search/playlist`。
- **FR-072**：搜索请求 MUST 携带 `keyword`、`source`、`page`、`limit`，并对关键词做 URL 编码。
- **FR-073**：搜索结果 MUST 解析并展示名称、歌手/作者、专辑、音源、封面、时长与可用音质。
- **FR-074**：搜索结果歌曲 MUST 可试听、收藏、加入歌单；专辑/歌单 MUST 可下钻获取曲目。
- **FR-075**：搜索 MUST 支持分页/加载更多，并保留关键词与范围；失败时展示原因与重试。
- **FR-076**：搜索历史 MUST 持久化（≤10 条）并支持清空。

**K. 服务器下载任务**

- **FR-077**：应用 MUST 支持提交服务器下载任务（`POST /api/download/add`），并传递曲目名称、歌手、专辑、音源、平台 ID、音质与目标目录。
- **FR-078**：下载页 MUST 拉取 `/api/download/list` 并映射状态（waiting/downloading/paused/completed/failed/await_*）。
- **FR-079**：任务 MUST 支持暂停、继续、重试、删除单条与清空已完成；危险操作需二次确认。
- **FR-080**：下载页 MUST 展示进度、已下载/总大小、速度、错误原因与目标路径。
- **FR-081**：任务状态 MUST 支持定时刷新（或手动刷新），并在完成后触发一次曲库同步。
- **FR-082**：下载页 MUST 区分「服务器下载」与本地导入文件，不得把服务器任务计入本机存储看板。

**L. 播客**

- **FR-083**：播客页 MUST 拉取 `/api/podcasts` 展示订阅列表，并支持 RSS URL 新增订阅。
- **FR-084**：节目详情 MUST 调用 `/api/podcasts/{id}/episodes?page&limit` 分页展示单集。
- **FR-085**：单集 MUST 可播放其音频地址，并记录本机播放进度（服务端无进度接口时）。
- **FR-086**：节目 MUST 支持刷新（`/refresh`）与取消订阅（`DELETE`），均需二次确认（取消订阅）。
- **FR-087**：播客与音乐 MUST 共用播放器与迷你播放器，支持播客 ±15 秒快退/快进。
- **FR-088**：服务端返回空列表时 MUST 展示空态与添加订阅入口，不得展示演示单集。

**M. 音源脚本管理**

- **FR-089**：音源管理 MUST 拉取 `/api/source/list` 并展示名称、作者、版本、支持平台、启用状态与健康等级。
- **FR-090**：应用 MUST 支持启用/停用脚本（`/api/source/activate`、`/api/source/deactivate`）。
- **FR-091**：应用 MUST 支持按 URL 导入脚本（`/api/source/import-url`）与导入脚本内容（`/api/source/import`）。
- **FR-092**：应用 MUST 支持切换脚本内单个平台的启用状态，并展示平台级健康统计（成功率、平均耗时、最近错误）。
- **FR-093**：导入/切换失败 MUST 展示服务端原因，且不得改变现有脚本状态。

**N. 服务器标签编辑**

- **FR-094**：标签编辑 MUST 通过 `/api/tag/read` 读取服务器文件的标签、封面与歌词状态。
- **FR-095**：在线匹配 MUST 调用 `/api/tag/match` 并展示候选来源、标题、歌手、专辑与封面。
- **FR-096**：应用 MUST 支持将候选应用到表单（`/api/tag/match-apply`）后再写入。
- **FR-097**：写入 MUST 调用 `/api/tag/write`，并在执行前明确提示"将修改服务器文件"并要求二次确认。
- **FR-098**：写入失败或取消 MUST 保证服务器文件不变；在线来源曲目 MUST NOT 提供写入入口。

**O. 首页模式与本地扫描**

- **FR-099**：原「发现」页签 MUST 更名为「首页」，作为第一个底部页签，图标与选中态与其他页签一致。
- **FR-100**：首页 MUST 提供「本地曲库 / 柠檬音乐服务器」分段切换，切换后立即展示对应内容并记住选择。
- **FR-101**：未添加任何服务器时 MUST 强制本地模式且不显示服务器错误；已添加服务器且无历史选择时 MUST 默认服务器模式。
- **FR-102**：本地模式 MUST 展示全部本地曲目、最近添加、曲目数/文件夹数/占用空间，并提供「添加音乐文件夹」「重新扫描」入口。
- **FR-103**：服务器模式 MUST 保留现有榜单/新歌/新碟/推荐歌单能力，并复用既有发现页数据与缓存。
- **FR-104**：添加文件夹 MUST 使用系统文件夹选择器（选择模式为文件夹），仅请求读取权限。
- **FR-105**：应用 MUST 对所选文件夹执行持久化授权（`ohos.permission.FILE_ACCESS_PERSIST` + `persistPermission`），并在冷启动时激活已持久化授权。
- **FR-106**：扫描 MUST 递归遍历所选目录，支持 mp3/flac/wav/m4a/aac/ogg/opus/ape 等常见格式，忽略其他文件。
- **FR-107**：扫描 MUST 读取音频标签（标题/歌手/专辑/时长/采样率/位深）与内嵌封面；标签缺失时使用文件名推导，封面缺失时使用程序化占位。
- **FR-108**：扫描 MUST 展示进度（已扫描/已发现/当前文件）与状态（未扫描/扫描中/完成/失败），并支持取消。
- **FR-109**：重复扫描 MUST 按「路径 + 大小 + mtime」增量更新：新增、删除、元数据变化均正确反映，不产生重复条目。
- **FR-110**：移除文件夹 MUST 二次确认，撤销持久化授权并移除其曲目；不影响其他文件夹与服务器数据。
- **FR-111**：本地模式 MUST 不依赖服务器即可播放、收藏（本地）、加入本地歌单与查看最近添加。
- **FR-112**：权限失效、目录不存在、文件损坏时 MUST 汇总提示并继续扫描其余文件，不崩溃。
- **FR-113**：本地曲库索引 MUST 持久化（路径、元数据、封面缓存、最后扫描时间），冷启动可恢复。
- **FR-114**：扫描不得阻塞 UI；进度更新频率 MUST 限制在约 200ms/次，列表可随扫描结果增量刷新。

**P. 底部沉浸光感栏**

- **FR-115**：底部导航 MUST 为整宽悬浮玻璃 Dock，使用沉浸式材质（THIN/ULTRA_THIN）并保留 `expandSafeArea` 底部延伸。
- **FR-116**：选中页签 MUST 有图标放大（约 1.12–1.2 倍）与轻微上浮，标签颜色/透明度渐现，过渡 ≤250ms；未选中项保持静态。
- **FR-117**：Dock 顶部 MUST 有 1–2px 高光描边/扫光效果，随选中切换有短促流光过渡。
- **FR-118**：正在播放时 MUST 在 Dock 上沿显示 2px 进度线（品牌色或封面主色渐变）；暂停时保留但降低亮度。
- **FR-119**：当前曲目有封面时 MUST 以低不透明度（8%–12%）将封面主色染入 Dock 背景；无封面使用品牌红。
- **FR-120**：Dock MUST 适配深/浅色主题与安全区；低算力/不支持沉浸光感时 MUST 降级为背景模糊+半透明底色。
- **FR-121**：迷你播放器与 Dock MUST 保持固定间距、不重叠页签；播放器展开、搜索、播客叠层打开时 Dock MUST 正确隐藏或避让。
- **FR-122**：Dock 与迷你播放器的组合高度 MUST 通过统一常量维护，页面内容底部留白随之调整，避免遮挡最后一项。

**Q. 底栏合并与去红**

- **FR-123**：迷你播放器 MUST 并入 Tabs 的自定义 tabBar 内容，与页签同行块共享同一层沉浸式系统材质，不得作为独立悬浮层叠在 Dock 上方。
- **FR-124**：Dock MUST 为单块整宽玻璃（左右 8vp、底部 8vp 留白），播放行在上、页签行在下，中间以 1px 分隔线或 6vp 间距区分。
- **FR-125**：Dock MUST NOT 使用任何不透明底色或色遮罩；仅保留系统模糊材质 + 1px 高光描边，底层内容可清晰透出。
- **FR-126**：无播放时 Dock 高度 MUST 收缩为仅页签（约 64）；有播放时扩展为约 124；高度变化 MUST 有 ≤200ms 过渡，内容底部留白同步更新。
- **FR-127**：播放行 MUST 提供封面、标题、歌手、播放/暂停、下一首，并支持点击打开全屏播放器。
- **FR-128**：进度线 MUST 位于整块 Dock 上沿并跨播放行+页签行，播放时品牌红或封面色渐变，暂停时降低亮度。

**R. 系统实况窗（AVSession）与后台播放**

- **FR-129**：应用 MUST 在首次播放时创建并激活 `audio` 类型 AVSession；会话对象 MUST 在后台播放期间保持存活。
- **FR-130**：AVSession MUST 设置元数据：assetId、title、artist、album、duration、mediaImage（封面 PixelMap 或路径）、lyric（LRC 原文，≤40960 字节）。
- **FR-131**：AVSession MUST 设置播放状态：state、position、speed、bufferedTime、loopMode、isFavorite、activeItemId。
- **FR-132**：AVSession MUST 注册控制命令：play、pause、stop、playNext、playPrevious、seek、fastForward、rewind、toggleFavorite、setLoopMode；并映射到 PlayerStore/LibraryStore。
- **FR-133**：切歌、暂停/播放、seek、收藏、循环模式变化时 MUST 在 1 秒内更新 AVSession 元数据与播放状态。
- **FR-134**：应用 MUST 申请 `ohos.permission.KEEP_BACKGROUND_RUNNING` 并在 EntryAbility 声明 `backgroundModes: ["audioPlayback"]`。
- **FR-135**：开始播放 MUST 启动 audioPlayback 长时任务；队列清空/停止/退出 MUST 取消长时任务并结束实况窗。
- **FR-136**：切后台/锁屏后播放 MUST 持续（受系统与耳机拔出等中断事件影响时按系统回调处理）。
- **FR-137**：AVSession 创建失败/权限被拒 MUST 不影响应用内播放，仅记录并降级。
- **FR-138**：歌词 MUST 以 LRC 字符串传入 `lyric`，超长截断到 40KB；无歌词时不设置该字段。
- **FR-139**：封面 MUST 解码为 PixelMap（≤512px）用于 mediaImage；失败时使用占位或省略，不影响播控。
- **FR-140**：应用退出/销毁 MUST 注销 AVSession 监听并销毁会话，避免残留实况窗。

**S. 首页顶部下拉**

- **FR-141**：首页第一行 MUST 为：左侧「首页」标题 + 搜索按钮；右侧两个下拉：音源下拉在左、模式下拉在最右。
- **FR-142**：模式下拉 MUST 提供「本地曲库」「柠檬音乐服务器」；无服务器时服务器项禁用并提示去设置。
- **FR-143**：音源下拉 MUST 提供酷我/网易云/QQ/酷狗/咪咕，选择后重新加载榜单/新歌/新碟/推荐并持久化。
- **FR-144**：本地模式 MUST 隐藏音源下拉；切回服务器模式 MUST 恢复显示并保持上次音源。
- **FR-145**：两个下拉 MUST 使用沉浸光感材质与统一胶囊样式，宽度自适应、不换行、不遮挡标题；小屏/横屏仍可用。
- **FR-146**：原顶部分段切换器与音源 Chip 行 MUST 移除，避免与下拉重复。

**T. 双层底栏与上滑折叠**

- **FR-147**：默认态 MUST 为「独立迷你播放器胶囊 + 独立整宽页签栏」，播放器在页签栏上方，间距 8–10vp。
- **FR-148**：迷你播放器 MUST 仅使用背景模糊 + 1px 高光描边 + 极低透明度的明暗层，禁止品牌红与专辑色遮罩；底层内容透出。
- **FR-149**：页签栏 MUST 保留 4 个页签（首页/资料库/下载/设置），使用 Tabs 的沉浸材质与悬浮样式。
- **FR-150**：无当前曲目时 MUST 隐藏迷你播放器，仅保留页签栏；内容底部留白同步收缩。
- **FR-151**：迷你播放器 MUST 展示封面、标题、歌手、播放/暂停、下一首、队列入口；点击非按钮区域打开全屏播放器。
- **FR-152**：进度线 MUST 使用 2px 品牌红/封面色渐变，播放时显示、暂停时降低亮度。
- **FR-153**：当首页/列表向上滚动超过阈值（约 120vp）时 MUST 进入折叠态：隐藏页签栏与完整播放器。
- **FR-154**：折叠态 MUST 显示紧凑胶囊：左侧首页圆钮 + 封面 + 标题/歌手 + 播放/暂停 + 下一首 + 队列。
- **FR-155**：折叠态点击首页圆钮 MUST 回到首页并展开页签栏；点击胶囊其余区域 MUST 打开全屏播放器。
- **FR-156**：向下滚动超过阈值或回到顶部 MUST 退出折叠态，恢复页签栏与完整播放器。
- **FR-157**：上滑折叠时顶部搜索框 MUST 收缩为圆形图标；展开态恢复搜索框。
- **FR-158**：切换主页面 MUST 重置折叠状态为展开；各页面滚动互不影响。
- **FR-159**：折叠/展开动画 MUST ≤250ms，内容底部留白在两种状态间平滑过渡，最后一项不被遮挡。
- **FR-160**：折叠胶囊 MUST 不遮挡系统手势区，且不与列表点击冲突；无播放时折叠态不得显示空播放器。

**U. 播放器收缩/展开动画**

- **FR-161**：打开全屏播放器 MUST 以迷你播放器矩形为起点放大到全屏，时长 280–320ms，缓动自然。
- **FR-162**：关闭全屏播放器 MUST 缩小并位移到当前迷你播放器矩形（或折叠胶囊矩形）后隐藏。
- **FR-163**：过渡 MUST 使用单一 `progress` 驱动位移/缩放/圆角/透明度，禁止两套播放器同时完整显示。
- **FR-164**：过渡期间底部栏 MUST 保持可见；迷你播放器在关闭动画结束时才显示，避免重复。
- **FR-165**：从折叠态打开的播放器 MUST 落回紧凑胶囊矩形，并保持折叠状态。
- **FR-166**：动画 MUST 可中断：切换过程中再次点击从当前位置继续，不跳变。
- **FR-167**：目标矩形 MUST 根据窗口宽高、底栏高度、折叠状态动态计算；旋转/分屏后重新计算。
- **FR-168**：过渡中播放器内容 MUST 随容器缩放，封面不闪白、不出现破图；文字可暂时缩小。
- **FR-169**：播放器内的浮层（队列/歌词调节/更多）打开时，关闭播放器 MUST 先收起浮层再执行收缩。
- **FR-170**：动画期间 MUST 禁用底层列表点击，结束后恢复。
- **FR-171**：无当前曲目时 MUST 不播放打开/关闭动画，直接返回。
- **FR-172**：低算力设备/减少动效设置下 MUST 降级为 150ms 淡入淡出，功能不变。

### 关键实体

- **服务器配置（ServerConfig）**：标识、名称、基础地址、用户名、Token（仅本机，含过期时间）、是否激活、最后连接时间、最后同步时间。
- **在线来源条目（OnlineTrackRef）**：平台、平台歌曲 ID（songId/songmid/hash/copyrightId 之一）、封面 URL、可选内嵌歌词、音质列表。
- **服务器下载任务（ServerDownloadTask）**：任务 ID、名称、歌手、专辑、音源、平台 ID、音质、状态、进度、文件路径、错误原因、创建/更新时间。
- **播客订阅（PodcastFeed）**：feed ID、标题、作者、封面、简介、单集数、订阅时间。
- **播客单集（PodcastEpisode）**：单集 ID、标题、音频 URL、时长、发布日期、简介、本机播放进度。
- **音源脚本（SourceScript）**：脚本 ID、名称、作者、版本、主页、平台能力表、启用状态、健康等级、最近探测结果。
- **标签快照（TrackTagInfo）**：文件路径、标题、歌手、专辑、年份、音轨号、流派、封面状态、歌词状态。
- **本地文件夹（LocalFolder）**：授权 URI、显示名、加入时间、最后扫描时间、文件数、失效标记。
- **本地扫描状态（LocalScanState）**：阶段（idle/scanning/done/error/cancelled）、当前文件、已扫描数、已发现数、新增/更新/删除数、错误汇总。
- **本地曲目（LocalTrack）**：文件 URI/沙箱路径、标题、歌手、专辑、时长、格式、大小、mtime、采样率、位深、封面缓存键、文件夹归属。
- **系统播控状态（AvSessionState）**：sessionId、是否激活、当前 assetId、播放状态、位置、循环模式、收藏、长时任务 ID、最后同步时间。
- **首页头部状态（HomeHeaderState）**：模式（local/server）、音源（kw/wy/tx/kg/mg）、两个下拉展开状态。
- **滚动折叠状态（ScrollChromeState）**：collapsed、lastOffset、direction、activeTab、threshold、searchCollapsed。
- **播放器过渡状态（PlayerTransitionState）**：progress（0=迷你矩形，1=全屏）、targetRect、sourceRect、animating、collapsedAtOpen。
- **会话（ServerSession）**：Token、用户标识、签发时间、是否有效、最后校验时间。
- **服务器曲目（ServerTrack）**：标识（路径哈希）、标题、歌手、专辑、时长、格式、码率、大小、采样率/位深、服务器路径、trackId、mtime、是否有内嵌封面、加入时间。
- **服务器专辑（ServerAlbum）**：标识、名称、歌手、曲目数、年份、样例路径/封面。
- **服务器歌手（ServerArtist）**：标识、名称、封面样例路径、专辑/曲目数。
- **服务器歌单（ServerPlaylist）**：标识、名称、封面、曲目键集合、曲目快照、曲目数、是否收藏智能歌单。
- **用户数据（ServerUserData）**：收藏列表、自建歌单、最近播放、配置。
- **同步状态（SyncState）**：阶段、进度、成功/失败、错误原因、最后成功时间、服务器标识。
- **本地曲目（LocalTrack）**：标识、元数据、沙箱路径、加入时间。
- **歌词（LyricDoc）**：逐行时间戳与文本、偏移、来源（内嵌/接口）。
- **封面缓存（CoverCacheEntry）**：服务器标识、路径或外链 URL、mtime、本地缓存文件、更新时间。
- **榜单（DiscoverToplist）**：标识、名称、封面、更新时间、音源。
- **发现歌单/专辑（DiscoverCollection）**：标识、名称、作者/歌手、封面、曲目数、音源、类型（推荐歌单/新碟）。

## Success Criteria *(mandatory)*

### 可衡量结果

- **SC-001**：使用有效服务器信息，从点击「连接测试」到显示成功 ≤ 5 秒（局域网），成功率 100%（10 次重复）。
- **SC-002**：登录后曲库同步 500 首以内 ≤ 15 秒；同步后本地曲目数量与服务器 `total` 完全一致（0 重复、0 遗漏）。
- **SC-003**：点击服务器曲目到开始出声 ≤ 2 秒（局域网，首包可用）；暂停/继续/拖动/切歌成功率 100%（10 次操作）。
- **SC-004**：封面首次加载 ≤ 1.5 秒，二次进入缓存命中 ≤ 100ms，且无破损图。
- **SC-005**：带时间戳歌词的当前行与播放进度偏差 ≤ 500ms。
- **SC-006**：收藏/取消收藏写回后，用另一客户端或重新登录验证，服务器状态一致率 100%（10 次操作）。
- **SC-007**：自建歌单的新建、重命名、删除、增删曲目写回后，服务器数据一致率 100%（各 3 次操作）。
- **SC-008**：读取用户数据失败时发起收藏，服务器收藏条目数量保持不变（0 覆盖）。
- **SC-009**：未配置/离线状态下，4 个主页面均展示可读空态与可操作入口，应用不崩溃，且无演示歌曲出现。
- **SC-010**：冷启动后会话、缓存曲库、设置与收藏状态保持；未重新输入密码即可继续使用。
- **SC-011**：断网、403/401、5xx、超时、HTML 响应五类异常均有可读提示，应用不退出。
- **SC-012**：手机竖屏、横屏、平板三形态巡检无内容裁切、无文字溢出、无不可点击控件。
- **SC-013**：服务器歌单中 ≥95% 的曲目条目可被解析并展示；抽取 3 条本地文件与 3 条在线来源条目，均可成功换取播放地址并开始播放。
- **SC-014**：发现页榜单数量与 `/api/discover/toplists` 返回一致（当前 36 个）；打开任一榜单可看到曲目并成功播放首曲。
- **SC-015**：新碟首发与推荐歌单各抽取 2 个，均可下钻获取曲目列表；切换音源后榜单内容发生变化且页面不崩溃。
- **SC-016**：搜索"周杰伦"返回 ≥10 条歌曲结果，搜索"古风"返回歌单结果；首条结果可播放，收藏后服务器收藏数 +1。
- **SC-017**：提交 1 个服务器下载任务后 3 秒内出现在列表；暂停/继续/重试/删除各操作 1 次均成功；完成后曲库同步能拉到新曲目。
- **SC-018**：添加 1 个有效 RSS 后节目出现在播客列表；展开单集并播放成功；取消订阅后从列表与服务器移除。
- **SC-019**：音源列表展示 ≥1 个启用脚本及其平台健康数据；启用/停用切换后状态与服务器一致。
- **SC-020**：标签读取返回标题/歌手/专辑；匹配返回 ≥1 个候选；取消写入时服务器文件 mtime 不变（0 修改）。
- **SC-021**：全部接入后，应用冷启动 → 登录 → 同步 → 播放 → 搜索 → 下载 → 播客 → 音源 → 标签，全链路无崩溃，异常均有可读提示。
- **SC-022**：服务器不可达时，所有在线模块（发现/搜索/下载/播客/音源/标签）均进入可恢复的错误态，不出现无限加载。
- **SC-023**：全新安装且无服务器时，首次启动 3 秒内进入首页本地模式并显示添加文件夹入口，无任何服务器错误弹窗。
- **SC-024**：选择一个含 100 首音频的文件夹，完整扫描 ≤30 秒；扫描结果数量与目录内音频文件数量一致（允许跳过损坏文件并汇总）。
- **SC-025**：重启应用后无需重新授权即可读取上次文件夹；重新扫描 100 首时无重复条目，删除的文件被移除。
- **SC-026**：切换首页模式 ≤300ms 完成；服务器模式内容与切换前发现页一致（榜单数 ≥1）。
- **SC-027**：底栏在浅/深色、有无封面、播放/暂停四种组合下均正确渲染高光、选中动画与进度线；截图对比无错位。
- **SC-028**：底栏 + 迷你播放器不遮挡任意页面最后一项（逐页滚动到底检查），且沉浸光感不支持时仍可用。
- **SC-029**：底栏截图中不存在品牌红大面积遮罩；播放行与页签行材质连续，属同一块玻璃。
- **SC-030**：无播放时 Dock 高度约 64，有播放时约 124；切换时内容底部留白同步变化，无跳动遮挡。
- **SC-031**：播放后 3 秒内系统播控中心/锁屏可见歌曲信息；点击暂停/下一首后应用内 1 秒内同步。
- **SC-032**：应用切后台/锁屏 30 秒，音乐持续播放；停止播放后长时任务取消。
- **SC-033**：系统播控显示歌词（LRC）与封面；无歌词/封面时不报错。
- **SC-034**：首页第一行同时可见音源下拉与模式下拉（模式最右）；本地模式音源下拉消失。
- **SC-035**：切换音源后榜单/推荐内容变化且不崩溃；切换模式后内容立即切换并重启保持。
- **SC-036**：小屏（≤360vp）与横屏下首页第一行不换行、不重叠、两个下拉均可点击。
- **SC-037**：默认态截图中播放器与页签栏为两层独立玻璃胶囊，间距 8–10vp，无红色遮罩。
- **SC-038**：无播放时播放器隐藏，页签栏居中；有播放时两者均显示且不重叠内容。
- **SC-039**：上滑 120vp 后页签栏消失，紧凑胶囊出现且包含首页圆钮/封面/标题/播放/下一首/队列。
- **SC-040**：折叠态点击首页圆钮回到首页并展开；下滑/回顶后页签栏恢复。
- **SC-041**：上滑后搜索框收为圆形图标，下滑恢复；两态切换 ≤250ms。
- **SC-042**：切换页签后折叠状态重置，无错位或空白。
- **SC-043**：折叠/展开过程中底部最后一项不被遮挡，手势区可正常返回桌面。
- **SC-044**：底栏与迷你播放器截图中不存在不透明底色/色遮罩，可看到底层内容（文字或封面）透过玻璃。
- **SC-045**：打开播放器时起点与迷你播放器矩形重合；关闭时终点与其重合（±4vp）。
- **SC-046**：折叠态打开/关闭播放器，终点为紧凑胶囊矩形，折叠状态保持。
- **SC-047**：连续 10 次打开/关闭，无白屏、无重复播放器、无错位。
- **SC-048**：动画期间点击底层列表无效，结束后可正常点击。
- **SC-049**：旋转后打开/关闭，落点仍对准当前迷你播放器/胶囊。
- **SC-050**：低算力/减少动效下退化为淡入淡出，仍可正常打开关闭。

## Assumptions

- 服务器实现与 Android 端 `LemonMusicProtocol` 所对接的柠檬音乐服务端接口一致（`/api/auth/*`、`/api/library/*`、`/api/play/*`、`/api/tag/*`）。
- 服务端可经局域网 HTTP 直连；若使用 HTTPS，证书由系统信任链校验，自签名证书不在本次支持范围。
- 本次接入：登录、曲库、播放、封面/歌词、收藏与歌单、发现页、全网搜索、服务器下载任务、播客、音源脚本管理、服务器标签编辑。本次不接入：Android 灵动岛/桌面小组件、应用自更新、在本机执行落雪/音源 JS 脚本（脚本由服务端执行，应用仅管理配置）。
- 标签写入具有破坏性：仅在用户二次确认后执行，且仅对服务器本地文件开放；在线来源曲目只读。
- 服务器下载为「下载到服务器曲库」，不实现"下载到手机本地"。
- 用户已在飞牛上部署服务端并拥有有效账号；服务器地址与凭据由用户在应用内填写，不写入代码或仓库。
- 曲库规模以万级以内为主；本期采用整库分页同步与内存缓存，不做增量 diff 与后台上传。
- 本地导入音频的格式支持范围由系统 AVPlayer 决定（MP3/FLAC/WAV/M4A 等）。
- 本地扫描采用「用户选择文件夹 + 持久授权」方案，不申请系统媒体库受限权限；音频标签/封面通过 `AVMetadataExtractor` 读取，失败回退文件名与程序化封面。
- 首页模式选择持久化；无服务器强制本地、有服务器且无历史默认服务器。
- 底部导航为「华为音乐风」**双层悬浮**：独立迷你播放器胶囊 + 独立悬浮页签栏；**完全去除不透明底色与色遮罩**，仅模糊+高光；上滑折叠为「首页圆钮 + 紧凑播放器」，下滑/回顶恢复；顶部搜索框同步收起。
- 全屏播放器与迷你播放器之间使用 280–320ms 的收缩/展开过渡，终点为迷你播放器或折叠胶囊矩形；低算力降级为淡入淡出。
- 音乐类实况窗通过 **AVSession Kit** 接入（系统播控中心/状态栏胶囊/锁屏自动展示），不使用 Live View Kit 自定义模板（音乐不在其开放场景内）；同时申请 `KEEP_BACKGROUND_RUNNING` 与 `audioPlayback` 长时任务。
- 首页顶部为两个下拉：音源在左、模式（本地/服务器）在最右；本地模式隐藏音源下拉。
- 演示数据将被移除；播客与下载页改为真实服务端数据，空列表时展示空态与添加入口。
